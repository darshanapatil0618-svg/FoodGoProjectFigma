# Food Go — Food Delivery Website

A responsive front-end college project built with HTML, CSS, and vanilla JavaScript.

## How to run
1. Extract `Food_Go_Website.zip`.
2. Open the `Food_Go_Website` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code **Live Server** extension and choose **Open with Live Server**.

No Node.js, database, or build tools are required.

## Included features
- Responsive dark theme with orange-red accents
- Home, categories, popular food cards, offers, services, About, Contact and footer
- Food search, category filters, vegetarian-only filter
- Interactive cart with quantity controls, remove buttons, delivery fee and total
- Demo login and registration forms, password visibility toggle
- Checkout form with Cash on Delivery and Online Payment selection
- Demo order confirmation with generated order ID
- Order tracking timeline
- Contact form success feedback
- Cart is saved for the current browser tab using session storage

## Important notes
- This is a **front-end prototype** for learning and college demonstration. Login, registration, contact, payment and order actions are simulated in the browser. They do not connect to a real server, database, delivery service, or payment gateway.
- Food photos are loaded from Unsplash and Google Fonts are loaded online, so an internet connection is needed for those external assets.
- Replace the sample contact details and add a backend before using this for real customers.
